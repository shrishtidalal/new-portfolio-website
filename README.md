# Shrishti Dalal — Portfolio Website

Personal portfolio built with Next.js 16 and Once UI.

## Run locally

```bash
npm install
npm run dev
```

## Quick edits

- Main site content: `src/resources/content.tsx`
- Theme/config: `src/resources/once-ui.config.ts`
- Blog posts: `src/app/blog/posts/*.mdx`
- Work/projects: `src/app/work/projects/*.mdx`
- Images/static files: `public/`

## Build

```bash
npm run build
npm run start
```
